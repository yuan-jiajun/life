# CLAUDE.md（trips 旅行板块）

旅游攻略笔记板块——记录每次旅行的行程与攻略。每个目的地以 `行程.html`（带样式、浏览器直接打开的单页 HTML）为主文件，攻略/花费/打包都整合进它；`网络情报.md`（Markdown）单列为情报池。

> 全局规则（改正式文件前先经用户同意、任何改动都不自动 commit）见仓库根 [`../CLAUDE.md`](../CLAUDE.md)，本文件不重复。

## 板块结构

```
destinations/<地区>/<子区>/   每个目的地一个文件夹（如 新疆/北疆）
  行程.html                主文件：逐日行程 + 景点玩法/避坑 + 预约·加油速查 + 花费 + 打包清单
  网络情报.md            联网采集的原始情报池（按日期分节追加，见下）
```

（攻略整理 skill 在仓库级 `../.claude/skills/plan-trip/`，见下「格式与方法」。）

样板看 `destinations/新疆/北疆/`，这是质量下限：`行程.html` 每天带里程车程/当日重点/早起错峰点，并整合景点玩法、避坑、预约速查、花费、打包。

## 写作约定

- **全中文**，目的地用 `地区/子区` 两级目录（如 `新疆/北疆/`）；只有一级也可单层（如 `日本/东京/` 或直接 `东京/`）。
- 文件间用相对链接互引（`[行程.html](行程.html)`）。
- `行程.html` 的产出标准：看完知道**该砍什么、哪里多待、哪天踩坑**，不是流水账。
- **不把未确认的网络情报直接写进 `行程.html`**——先进 `网络情报.md`，确认后再回灌。

## 网络情报与回灌（约定）

- 联网采集的增量先进 `destinations/<地区>/<子区>/网络情报.md`：**按日期分节追加**、标来源、标注全文还是仅摘要；不覆盖旧节、不直接动正式文件。顶部保留时效声明（限流/预约/票价以官方公众号当日为准）。
- 确认后才回灌进 `行程.html`；**回灌默认不改路线/天数**，只把已有计划做扎实，只补缺口、矛盾两面呈现。
- 回灌正式文件须先经用户同意、且不自动 commit（见根 `../CLAUDE.md`「改动规则」）。

## 格式与方法：以 plan-trip skill 为准

收集攻略、规划行程、研究某地怎么玩时走 `/plan-trip`（`../.claude/skills/plan-trip/SKILL.md`）：联网采集→提炼成观点→因地制宜成稿的工作流。

**所有操作细节都在 skill 里，本文件不重复**——包括采集查询配方、403 抓取破解（`r.jina.ai`）、`行程.html` 的每日表格 + 当日重点分点 + 硬约束加粗、以及里程/车程的标注口径。改 `行程.html` 前先翻 skill 的「阶段四 · 成稿」。
