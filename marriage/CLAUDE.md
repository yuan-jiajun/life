# CLAUDE.md（marriage 婚前商议板块）

婚前商议事项板块——记录结婚前需要和对象谈清楚、达成共识的事（房产、双方父母、钱怎么花/还、传家宝等）。不是婚礼筹备，重点是**把分歧谈拢、把约定落到字面**。按需建文件，不预建空目录。

> 全局规则（改正式文件前先经用户同意、任何改动都不自动 commit）见仓库根 [`../CLAUDE.md`](../CLAUDE.md)，本文件不重复。

## 板块结构（按需建立）

```
待商议事项.md    需要谈的事项清单，每条记「现状 / 各自想法 / 结论」三段
```

后续如某类事项内容变多，再单独拆文件（如 `房产.md`、`双方父母.md`），并回这里补一行。

## 写作约定

- **全中文**，Markdown。
- 每个事项按三段记：
  - **现状**：客观事实、约束、相关政策/数字。
  - **各自想法**：双方各自的诉求与顾虑，分开写、不替对方下结论。
  - **结论**：谈定后的约定；未谈定标「待定」，并写清卡在哪。
- 涉及钱、政策、时间的，写清来源与确认状态（已定 / 待定 / 待核实）。
- 文件间用相对链接互引。
