# 东京 旅游攻略

> 这是一个示例文件，可以复制本文件夹作为新目的地的起点。

## 概况

- **最佳季节**：3-4 月（樱花）、11 月（红叶）
- **建议天数**：5-7 天
- **货币**：日元（JPY）
- **语言**：日语（主要景点有中英文标识）

## 景点

| 景点 | 区域 | 推荐理由 | 门票 |
| ---- | ---- | -------- | ---- |
| 浅草寺 | 浅草 | 经典地标 | 免费 |
| 涩谷十字路口 | 涩谷 | 著名街景 | 免费 |
| 上野公园 | 上野 | 赏樱、博物馆 | 免费 |

## 美食

- 寿司、拉面、天妇罗
- 居酒屋体验

## 交通

- 西瓜卡（Suica）/ 西瓜卡
- JR Pass 是否划算视行程而定

## 住宿建议

- 新宿 / 涩谷：交通便利，热闹
- 浅草 / 上野：性价比高

## 小贴士

- 多数地方可刷卡，但备些现金
- 电车末班车较早，注意时间
