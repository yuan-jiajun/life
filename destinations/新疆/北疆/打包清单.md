# 新疆 · 北疆 打包清单

> 北疆昼夜温差大、紫外线强、海拔点多，一年四季的衣服都要带一点，可叠穿。

## 证件 & 钱

- [ ] 身份证、驾驶证
- [ ] 银行卡
- [ ] 少量现金应急（500–1000）
- [ ] 机票 / 租车单 / 酒店预订单

## 衣物

### 防晒

- [ ] 墨镜
- [ ] 防晒衣 / 防晒面罩
- [ ] 遮阳帽
- [ ] 防晒霜（喷雾当地买也行）

### 防寒（海拔 3000m+ 会降温）

- [ ] 秋裤、抓绒裤
- [ ] 冲锋衣 / 抓绒或羽绒内胆
- [ ] 针织帽、轻薄手套
- [ ] 短袖、长裤

### 其他

- [ ] 拖鞋、睡衣、耳塞
- [ ] 拍照衣服 / 裙子（白裙配薰衣草、草原很出片）

## 生活用品

- [ ] 洗漱用品、护手霜、保湿、唇膏
- [ ] 充电器、充电宝、数据线
- [ ] 雨衣 / 雨伞 / 鞋套
- [ ] 防蚊用品（草原毡房虫多）
- [ ] 牙线、湿巾、湿厕纸、纸巾、垃圾袋、指甲刀

## 药品

- [ ] 晕车贴 / 晕车药
- [ ] 感冒药、肠胃药
- [ ] 维生素、创可贴

## 拍摄装备（按需）

- [ ] 长焦镜头
- [ ] 无人机（景区飞行需入口登记报备）
- [ ] Pocket / 运动相机
- [ ] 移动硬盘、读卡器、扩展坞
