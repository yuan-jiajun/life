# 新疆 · 北疆 行程（12 天优化版）

- **出行时间**：8 月，YYYY-MM-DD 至 YYYY-MM-DD
- **出发地**：成都（飞乌鲁木齐落地租车）
- **同行人**：（4 人轮换驾驶最佳）
- **车型**：普通 SUV / 轿车即可（铺装路为主），不建议坦克 300
- **预算**：见 [花费.md](花费.md)

## 路线总览

```
乌鲁木齐 → 赛里木湖（核心） → 伊宁（补给）
        → 伊犁环线（夏塔 / 库尔德宁 / 那拉提）
        → 昭苏 / 伊昭公路 → 唐布拉 + 独库北段
        → 奎屯 / 独山子 →（可选）喀纳斯 / 禾木 → 乌鲁木齐返程
```

判断行程是否合理只看一句话：**有没有连续 2 天「不赶路、只玩一个地方」**（如赛里木湖 1.5 天 / 草原放慢 1 天）。

## 每日行程

### Day 1　成都 → 乌鲁木齐

- 落地取车，国际大巴扎 citywalk，领馆巷/和田二街晚餐，傍晚红光山大佛寺。
- 宿乌鲁木齐。

### Day 2　乌鲁木齐 → 赛里木湖（直达）

- 约 500+ 公里，走连霍高速；时间充裕可在 S101 / 安集海大峡谷沿途取舍 1–2 个点（抓重点，别全停）。
- 宿赛里木湖边。

### Day 3　赛里木湖（完整环湖 + 松树头）

- 顺时针环湖，松树头徒步看全景，亲水滩看天鹅花海，等日落。
- 宿赛里木湖边（第 2 个白天）。

### Day 4　赛里木湖 → 伊宁

- 看日出（视天气）→ 果子沟大桥 → 六星街 / 喀赞其，可顺路薰衣草。
- 宿伊宁。

### Day 5　伊宁 → 夏塔（核心日，需早起）

- 走伊昭公路（先加满油）→ 白石峰观景台 → 昭苏（湿地公园天马浴河表演）→ 夏塔附近住宿。
- 宿夏塔 / 昭苏。

### Day 6　夏塔 → 库尔德宁 / 恰西（二选一）

- 早起错峰玩夏塔（转运桥下车 → 将军桥徒步），下午转场草原。
- 宿新源 / 特克斯（顺路可逛特克斯八卦城，晚上灯光航拍好看）。

### Day 7　草原深度体验（放慢节奏）

- 库尔德宁中沟进东沟出，或恰西画卷观景台；这一天刻意慢下来，不赶路。
- 宿新源。

### Day 8　唐布拉 → 独库北段 → 乌鲁木齐方向

- 走 S315 唐布拉百里画廊（走走停停，可选狗熊沟）→ 乔尔玛烈士陵园 → 独库北段。
- **独库北段留足时间**，天色晚就宿奎屯 / 独山子。

### Day 9　独山子 → 魔鬼城 → 五彩滩

- 独山子大峡谷（可选）→ 乌尔禾魔鬼城（只走核心区，防暑）→ 五彩滩（看日落）。
- 宿克拉玛依 / 布尔津。

### Day 10　喀纳斯（如坚持要去）

- 走阿禾公路，玩三湾 + 观鱼台；不赶。住贾登峪或景区内。
- 宿喀纳斯 / 贾登峪。

### Day 11　禾木 or 返回乌鲁木齐

- 去禾木看晨雾轻徒步（住 1 晚更好），或直接返乌鲁木齐。
- 宿禾木 / 乌鲁木齐。

### Day 12　乌鲁木齐 → 成都

- 半天自由活动：红山干果市场 / 金泉商城买伴手礼。还车，返程。

## 备注

- 若想更轻松：**砍掉 Day 10–11 的喀纳斯/禾木**，把省出的 2 天加到伊犁草原带（夏塔住温泉酒店看日出、再加喀拉峻/那拉提其一），即「伊犁 70% + 阿勒泰 30%」的最优解。
- 夏塔、赛里木湖松树头、独库北段都要早起错峰。
- 那拉提需提前抢票，抢不到就不去。
