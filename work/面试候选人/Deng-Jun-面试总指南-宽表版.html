快速打法（对齐 JD 技术岗）

JD 要求 Java 后端、Spring 体系、关系库与 SQL 优化、Maven/Git、Linux/Docker，以及分布式开发与线上排障。候选人履历偏高级技术经理，面试不要按架构岗铺开；用 60 分钟验证「JD 硬技能是否仍扎实」+「是否愿意做实施交付型开发」。

JD 对齐主线（按优先级）

  • 货拉拉全链路灰度：分布式服务治理、熔断限流、集成与发布。
  • 财务对账系统：MySQL 高吞吐、SQL/索引优化、幂等与一致性。
  • OrionHealth Pipeline：Docker、Ansible、Kafka、线上问题定位。
  • 飞书 eLearning：消息可靠性、集成测试边界、故障修改闭环。
  • 搜款网推荐/RAG：JD 非核心，仅作真实性抽检，不占主时间。

必问开场（技术向）

  • 最近 2 年是否仍写 Java/Spring 代码？频率、场景、本人负责模块。
  • 选一个与 JD 最贴近的项目（分布式 + DB + 排障），画模块图并讲接口与数据流。
  • 说一个线上 Bug/故障：如何发现、定位、修复、回归与防复发。
  • 功能需求到上线：需求理解、开发自测、联调集成测试的分工与做法。

风险假设

  • 资历超标：JD 要求 2 年+，需确认动机、薪资预期、是否接受 IC 交付岗。
  • 管理脱离编码：Spring/Hibernate/SQL 细节若答不出，不适合本 JD。
  • 技术栈偏移：近年偏算法/RAG，需验证 Java 后端基本功是否退化。
  • 项目跨度大，必须连续追问本人贡献边界，防止「只讲团队成果」。

方向 主问题 满意回答要点 风险信号
Java 基础 HashMap 与 ConcurrentHashMap 区别？volatile 能否保证原子性？线程池核心参数如何设？ 能讲桶结构、扩容、线程安全分段/CAS；volatile 只保证可见性有序性；线程池需结合队列、拒绝策略和业务隔离。 只会背八股定义，举不出项目中的并发问题。
Spring Boot @Transactional 失效场景？Bean 生命周期与循环依赖怎么处理？ 自调用、非 public、异常类型、传播行为；三级缓存、构造器注入避免循环依赖。 只说「用注解就行」，讲不清 AOP 代理与事务边界。
ORM / Hibernate 什么是 N+1？懒加载异常怎么避免？JPA 与 MyBatis 你会怎么选？ fetch join / batch size；Open Session In View 利弊；按复杂 SQL 与对象模型权衡选型。 多年 Java 却说不清 Session 与 SQL 生成关系。
SQL 优化 一条订单查询变慢，排查步骤？联合索引最左前缀？ 执行计划、索引命中、回表、锁等待、数据量变化；能结合对账/同步项目讲批写与索引取舍。 只会「加索引」，没有执行计划与业务口径。
分布式 接口幂等如何实现？服务超时重试要注意什么？ 业务唯一键、Token、状态机；重试需幂等、隔离、熔断，避免重试风暴。 把「再调一次」当幂等方案。
工程工具 Maven 依赖冲突怎么解？Git flow 或 trunk-based 你用过哪种？ dependencyManagement、排除传递依赖；能讲分支、发布、hotfix 实际流程。 从未处理过依赖树或合并冲突。
Linux / Docker CPU 高如何定位？Docker 镜像瘦身常见手段？ top/pidstat/jstack 或 async-profiler；多阶段构建、精简基础镜像、分层缓存。 只会 docker run，没做过部署或排障。
Ansible Playbook 如何保证幂等？部署失败如何回滚？ 模块幂等、idempotent 声明、check mode；版本化配置、上一版本 artifact 回切。 简历写 Ansible 但讲不出具体 Playbook 结构。（可对照 OrionHealth 经历深挖）
编码实操（可选） 滑动窗口限流 或 按业务键去重计数（15 分钟）。 边界时间窗、并发安全、内存占用；能写可运行代码并讨论分布式扩展。 无法写出基本结构或忽略并发。
