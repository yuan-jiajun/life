  - SIP UC Gateway B2BUA：用于 Incoming 和 Outgoing SIP 消息转发，支持运行时配置不同 SIP 二级网关。
  - TAS：B2BUA 特定二级网关，提供企业网总机服务端功能。
- 能力标签：
  - SIP
  - RFC3261
  - ISUP
  - RTP
  - B2BUA
  - 通信协议栈
- 面试可追问：
  - SIP 协议栈中事务、会话、路由如何处理？
  - B2BUA 和 Proxy 的区别是什么？
  - 信令转换中的异常和兼容性如何处理？
  - 运行时配置网关如何保证稳定性？
