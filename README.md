## 怎么整理一份新攻略

仓库内置了 `plan-trip` 工作流（`.claude/skills/plan-trip/`）。在 Claude Code 里说"帮我整理 XX 的攻略"或运行 `/plan-trip`，它会：

1. **采集** —— 联网搜集攻略、避坑、真实游记，落到 `网络情报.md`；
2. **提炼** —— 景点分级、避坑清单、路线取舍、节奏检验；
3. **成稿** —— 整合进主文件 `行程.html`，硬约束（加油、抢票、限流）绑到对应那天。

具体方法与约定见 [`CLAUDE.md`](CLAUDE.md)、[`trips/CLAUDE.md`](trips/CLAUDE.md) 和 skill 文档。

## 约定

- 改任何正式文件前先确认，未确认的网络情报只进 `网络情报.md`。
- 预约/限流/票价每年都变，以官方公众号当日为准。
