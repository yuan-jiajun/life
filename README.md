## 目录结构

每个目的地放在 `destinations/<地区>/<子区>/` 下（如 `新疆/北疆/`），两个文件：

| 文件 | 内容 |
| ---- | ---- |
| `行程.html` | **主文件，带走的就是它**：逐日行程 + 景点玩法/避坑 + 预约·加油速查 + 花费 + 打包清单，整合在一份里 |
| `网络情报.md` | 联网采集的原始情报池，按日期分节追加；确认后回灌进 `行程.html` |

样板看 `destinations/新疆/北疆/`，那是质量下限。

## 怎么整理一份新攻略

仓库内置了 `plan-trip` 工作流（`.claude/skills/plan-trip/`）。在 Claude Code 里说"帮我整理 XX 的攻略"或运行 `/plan-trip`，它会：

1. **采集** —— 联网搜集攻略、避坑、真实游记，落到 `网络情报.md`；
2. **提炼** —— 景点分级、避坑清单、路线取舍、节奏检验；
3. **成稿** —— 整合进主文件 `行程.html`，硬约束（加油、抢票、限流）绑到对应那天。

具体方法与约定见 [`CLAUDE.md`](CLAUDE.md) 和 skill 文档。

## 约定

- 改 `行程.html` 前先确认，未确认的网络情报只进 `网络情报.md`。
- 预约/限流/票价每年都变，以官方公众号当日为准。
