## 使用说明

每个目的地放在 `destinations/<地区>/<子区>/` 下（如 `新疆/北疆/`），里面可以包含：

- `攻略.md` —— 景点、美食、交通、住宿
- `行程.md` —— 按天安排的具体行程
- `花费.md` —— 预算与实际开销
- `照片/` —— 相关图片
