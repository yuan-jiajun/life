# 旅游攻略笔记

记录每次旅行的攻略、行程和心得。

## 目录

- [行程清单](destinations/)
- [打包清单模板](templates/打包清单.md)
- [行程模板](templates/行程模板.md)

## 已记录的目的地

| 目的地 | 时间 | 状态 |
| ------ | ---- | ---- |
| 示例：东京 | 2026-06 | 计划中 |

## 使用说明

每个目的地一个文件夹，放在 `destinations/` 下，里面可以包含：

- `攻略.md` —— 景点、美食、交通、住宿
- `行程.md` —— 按天安排的具体行程
- `花费.md` —— 预算与实际开销
- `照片/` —— 相关图片
