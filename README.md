## 目录结构

每个目的地放在 `destinations/<地区>/<子区>/` 下（如 `新疆/北疆/`），一个文件夹包含：

| 文件 | 内容 |
| ---- | ---- |
| `攻略.md` | 景点分级、避坑、路线方案对比（有观点，不是流水账） |
| `行程.md` | 逐日行程，每天带里程/车程、当日重点、住宿 |
| `花费.md` | 预算与实际开销 |
| `打包清单.md` | 按需 |
| `网络情报.md` | 联网采集的原始情报池，按日期分节追加 |

样板看 `destinations/新疆/北疆/`，那是质量下限。

## 怎么整理一份新攻略

仓库内置了 `plan-trip` 工作流（`.claude/skills/plan-trip/`）。在 Claude Code 里说"帮我整理 XX 的攻略"或运行 `/plan-trip`，它会：

1. **采集** —— 联网搜集攻略、避坑、真实游记，落到 `网络情报.md`；
2. **提炼** —— 景点分级、避坑清单、路线取舍、节奏检验；
3. **成稿** —— 因地制宜写进 `攻略.md` / `行程.md`，硬约束（加油、抢票、限流）绑到对应那天。

具体方法与约定见 [`CLAUDE.md`](CLAUDE.md) 和 skill 文档。

## 约定

- 改正式文件（攻略/行程等）前先确认，未确认的网络情报只进 `网络情报.md`。
- 预约/限流/票价每年都变，以官方公众号当日为准。
